# Exercicis per casa


Pugeu els exercicis o intents encara que no estiguin bé, dins una carpeta amb el vostre cognom.
Els exercicis que heu de fer per casa es son els següents

· **Exercici 12** , normal com hem fet els altres

· **Exercici 13**, aquí es demana una lletra (tipus Char) recordem que per demanar un char al scanner es demana *teclado.nextLine().charAt(0)* i això genera el char

· **Exercici 14**, el menu almenys que mostri 3 divises, i tu puguis triar, per exemple d'execució:

          Cuantos euros tienes? *por ejemplo usuario pone 10*
                          a - Dolar
                          b - Libra
                          c - Yen
                          Esperando opción: ___

  I tu escrius b, t'haura de transformar els 10 euros a Libra.
